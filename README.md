# MassageBot

Telegram-бот для записи к массажисту.

## Возможности
- Запись клиента: услуга, день, свободное время
- Защита от двойной записи
- Панель мастера `/admin`: записи по дням и отмена
- Уведомление мастеру о новой записи
- Напоминание клиенту за 2 часа до сеанса

## Технологии
Python 3.12, aiogram 3, SQLite

## Запуск
1. `pip install -r requirements.txt`
2. Скопировать `.env.example` в `.env` и заполнить:
   - `BOT_TOKEN` — токен бота от @BotFather
   - `ADMIN_ID` — Telegram ID мастера (можно узнать командой `/myid`)
   - `TIMEZONE` — часовой пояс салона, например `Europe/Moscow` (по нему считаются свободные слоты и напоминания)
3. `python main.py`
